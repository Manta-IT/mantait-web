Ponuka

Dve varianty podľa vašej potreby

Web Standard pre firmy, na ktorých webe skutočne stojí ich biznis. Web Quick pre firmy, ktorým stačí web ako vizitka - do týždňa, bez zložitostí.

FAQ

Časté otázky

Aký je rozdiel medzi Web Quick a Web Standard?

Web Quick je jednoduchá vizitka. Stránka o firme, služby, kontakt, prípadne referencie. Zmeny v texte alebo obrázkoch robíme po dohode. Vhodný, ak máte malú firmu alebo živnosť a web má slúžiť hlavne ako vizitka.

Web Standard má jednoduchú správu obsahu - sami si meníte texty, obrázky, pridávate články alebo referencie. Väčší rozsah, optimalizácia pre vyhľadávače, Google Analytics. Vhodný pre firmy, ktoré chcú web pravidelne aktualizovať.

Pre koho sú tieto weby vhodné?

Web Quick sedí remeselníkom, jednotlivým podnikateľom a malým firmám. Kvetinárstvo, inštalatér, advokát, kozmetický salón, malá obchodná firma.

Web Standard sedí menším a stredným firmám, ktoré potrebujú seriózny web. Distribútorom, výrobným firmám, službám so zamestnancami, neziskovým organizáciám.

Používate AI? Ako to ovplyvní výsledok?

Áno, využívam AI na generovanie návrhov dizajnu, kódu a textov. Web vediem celý sám a AI mi šetrí čas, ktorý by som inak platil tímu. Vďaka tomu je hotový rýchlo a za zlomok obvyklej ceny.

Každý web ale prechádza mojou kontrolou. Štruktúru, dizajn a kľúčové prvky ladím ručne. AI nerozhoduje za mňa. Výsledok je váš web na mieru, nie šablóna.

Ako je to s doménou a hostingom? Kde web pobeží?

Web hostujem na Cloudflare alebo podobne modernej službe. Hosting je rýchly, bezpečný a v základnej variante často zadarmo. Účet zakladám na vaše meno - hosting aj doména patria vám, nie mne.

Ak máte existujúcu doménu (napr. firma.cz), pomôžem s presmerovaním. Ak doménu ešte len potrebujete, odporučím a pomôžem zaregistrovať. Cena registrácie domény (cca 13 EUR ročne) nie je v cene webu.

Čo ak budem chcieť web neskôr rozšíriť alebo upraviť?

Drobné úpravy riešim operatívne. Väčšie rozšírenie nacením podľa rozsahu, typicky 1-2 dni práce. Web nebeží na drahej platforme s mesačnými poplatkami - úpravy vás nestoja nič navyše.

Ak váš web postupne narastie a budete potrebovať plnohodnotný web, môžeme prejsť na Web Standard - štruktúra a doména zostáva.
