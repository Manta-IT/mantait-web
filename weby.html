FAQ

Časté otázky

Jaký je rozdíl mezi Web Quick a Web Standard?

Web Quick je jednoduchá vizitka. Stránka o firmě, služby, kontakt, případně reference. Změny v textu nebo obrázcích děláme po domluvě. Vhodný, pokud máte malou firmu nebo živnost a web má hlavně sloužit jako vizitka.

Web Standard má jednoduchou správu obsahu - sami si měníte texty, obrázky, přidáváte články nebo reference. Větší rozsah, optimalizace pro vyhledávače, Google Analytics. Vhodný pro firmy, které chtějí web pravidelně aktualizovat.

Pro koho jsou tyto weby vhodné?

Web Quick sedí řemeslníkům, jednotlivým podnikatelům a malým firmám. Květinářství, instalatér, advokát, kosmetický salon, malá obchodní firma.

Web Standard sedí menším a středním firmám, které potřebují seriózní web. Distributorům, výrobním firmám, službám se zaměstnanci, neziskovým organizacím.

Používáte AI? Jak to ovlivní výsledek?

Ano, využívám AI pro generování návrhů designu, kódu a textů. Díky tomu jsem schopný dodat profesionální web mnohem rychleji a levněji, než kdyby vše dělal člověk od nuly. U klasické agentury byste za podobný web zaplatili 80 000 - 200 000 Kč. Já dodám rychleji a levněji díky AI.

Každý web prochází mou kontrolou. Strukturu, design a klíčové prvky ladím ručně. AI mi pomáhá s rychlostí, ne s rozhodováním. Výsledek je váš web na míru, ne šablona.

Jak je to s doménou a hostingem? Kde web pojede?

Web typicky hostujeme u Cloudflare nebo podobné moderní služby. Hosting je rychlý, bezpečný a v základní variantě často zdarma. Účet zakládáme na vás - hosting i doména jsou ve vašem vlastnictví, ne v mém.

Pokud máte stávající doménu (např. firma.cz), pomůžu s přesměrováním. Pokud doménu teprve potřebujete, doporučím a pomohu zaregistrovat. Cena registrace domény (cca 300 Kč ročně) není v ceně webu.

Co když budu chtít web později rozšířit nebo upravit?

Žádný problém. Drobné úpravy řešíme operativně. Větší rozšíření naceníme podle rozsahu - typicky 1-2 dny mé práce. Web není zamčený do žádné drahé platformy, takže vás úpravy nestojí měsíční poplatky navíc.

Pokud z malé webovky postupně narostete a budete potřebovat plnohodnotný web, můžeme přejít na Web Standard - struktura a doména zůstávají.
