Pro malé a střední firmy, řemeslníky a podnikatele, kteří dnes web nemají nebo mají takový, za který se stydí. Díky AI dodám profesionální web rychle a za rozumnou cenu.

Nabídka

Dvě varianty podle vaší potřeby

Web Standard pro firmy, na jejichž webu skutečně stojí jejich byznys. Web Quick pro firmy, kterým stačí web jako vizitka - do týdne, bez složitostí.

Web na míru se snadnou správou textů a obrázků

Profesionální web s vlastním designem a strukturou. Postavený na moderních technologiích, optimalizovaný pro vyhledávače i rychlost. Můžete si sami měnit texty a obrázky bez programátora. Vhodný pro firmy, které chtějí web jako součást businessu.

FAQ

Časté otázky

Jaký je rozdíl mezi Web Quick a Web Standard?

Web Quick je jednoduchá vizitka. Stránka o firmě, služby, kontakt, případně reference. Změny v textu nebo obrázcích děláme po domluvě. Vhodný, pokud máte malou firmu nebo živnost a web má hlavně sloužit jako vizitka.

Web Standard má jednoduchou správu obsahu - sami si měníte texty, obrázky, přidáváte články nebo reference. Větší rozsah, optimalizace pro vyhledávače, Google Analytics. Vhodný pro firmy, které chtějí web pravidelně aktualizovat.

Pro koho jsou tyto weby vhodné?

Web Quick sedí řemeslníkům, jednotlivým podnikatelům a malým firmám. Květinářství, instalatér, advokát, kosmetický salon, malá obchodní firma.

Web Standard sedí menším a středním firmám, které potřebují seriózní web. Distributorům, výrobním firmám, službám se zaměstnanci, neziskovým organizacím.

Používáte AI? Jak to ovlivní výsledek?

Ano, využívám AI pro generování návrhů designu, kódu a textů. Web vedu celý sám a AI mi šetří čas, který bych jinak platil týmu. Díky tomu je hotový rychle a za zlomek obvyklé ceny.

Každý web ale prochází mou kontrolou. Strukturu, design a klíčové prvky ladím ručně. AI nerozhoduje za mě. Výsledek je váš web na míru, ne šablona.

Jak je to s doménou a hostingem? Kde web pojede?

Web hostuji u Cloudflare nebo podobně moderní služby. Hosting je rychlý, bezpečný a v základní variantě často zdarma. Účet zakládám na vaše jméno - hosting i doména patří vám, ne mně.

Pokud máte stávající doménu (např. firma.cz), pomůžu s přesměrováním. Pokud doménu teprve potřebujete, doporučím a pomohu zaregistrovat. Cena registrace domény (cca 300 Kč ročně) není v ceně webu.

Co když budu chtít web později rozšířit nebo upravit?

Drobné úpravy řeším operativně. Větší rozšíření nacením podle rozsahu, typicky 1-2 dny práce. Web neběží na drahé platformě s měsíčními poplatky - úpravy vás nestojí nic navíc.

Pokud váš web postupně naroste a budete potřebovat plnohodnotný web, můžeme přejít na Web Standard - struktura a doména zůstává.
